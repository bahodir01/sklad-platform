# Ветка APP — интерфейсы (CRM, дашборды, админки)

Активирует базу `interface-design` (lig. проверить в репозитории, лежит в
`vendor/interface-design/`). Философия: дизайн для плотных, функциональных интерфейсов
в духе Linear, Notion, Stripe. Не маркетинг.

## Когда активна
project_type ∈ { crm, dashboard, admin, webapp, mobile }.

## Что важно в этой ветке (иначе, чем в маркетинге)
- Плотность и иерархия данных важнее «воздуха». Экран должен вмещать работу, не пустоту.
- Таблицы, фильтры, формы, состояния (пусто/загрузка/ошибка/успех) — first-class граждане.
- Навигация: sidebar / topbar, хлебные крошки, разделы. Консистентность между экранами.
- Плотностный режим (comfortable / compact) как параметр.
- Память решений: зафиксируй выбранные токены и паттерны, чтобы дизайн не «дрейфовал»
  между экранами и сессиями (interface-design умеет сохранять в system.md).

## Обязательные экраны для CRM/дашборда
1. Каркас приложения (app shell): sidebar + topbar + область контента.
2. Дашборд: карточки-метрики (KPI), графики, последняя активность.
3. Список сущностей: таблица с сортировкой, фильтрами, пагинацией, bulk-действиями.
4. Карточка/деталь сущности: вкладки, поля, связанные данные, действия.
5. Формы: создание/редактирование со всеми состояниями валидации.
6. Настройки: разделы, переключатели, профиль.
Бери `brief.data_entities`, чтобы понять, какие сущности и метрики нужны.

## Как применять стиль
Пресет клиента → база. Для интерфейсов подходят corporate, minimal, а из дизайн-систем —
linear/stripe/vercel/notion. Overrides клиента поверх. Токены генерируй с семантическими
ролями (surface, border, text, accent, success/warning/danger) — они критичны для таблиц и статусов.

## Выход
React (предпочтительно, для интерактивных таблиц/форм) или HTML. Общие компоненты
(shell, table, card, form, button, badge) — один раз, затем экраны переиспользуют их.

## Делегирование
Экспертиза по компонентам, состояниям и консистентности — в interface-design.
Этот файл фиксирует набор обязательных экранов и приоритет плотности над «воздухом».
